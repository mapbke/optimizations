# optimizations

Набор инструментов для Windows 11, который помогает убрать лишнюю фоновую нагрузку и настроить плавность рабочего стола и игр. В меню можно проверить частоту монитора, настроить автозагрузку, отключить захват игр и закрыть выбранные приложения.

Эффект зависит от причины рывков. Отключение записи может помочь, если она была включена и нагружала систему. Более высокая частота монитора делает движение на экране плавнее, если предыдущая частота была ниже. Настройки оформления меняют вид и скорость переходов в интерфейсе. Замеров этой сборки на разных ПК пока нет.

## Быстрый старт

1. [Скачайте ZIP ветки public-release](https://github.com/mapbke/optimizations/archive/refs/heads/public-release.zip) и распакуйте его в обычную папку с правом записи.
2. Запустите [START.cmd](START.cmd) из своей учётной записи Windows. Для обычного меню права администратора не нужны. В меню используются короткие названия на английском, расшифровка ниже.
3. Начните с частоты монитора и автозагрузки. Остальные пункты включайте по одному и проверяйте, как изменилось поведение в привычном сценарии.

Выберите пункт по номеру и нажмите Enter. Меню перерисовывается после каждого действия. Справа от пунктов **3, 5 и 6** отображается состояние сохранённых настроек: `(ACTIVATED)`, если все значения совпадают с выбранной настройкой, или `(INACTIVE)`, если требуется применение. `(UNKNOWN)` означает, что меню не смогло прочитать состояние. Для применения введите `Y`, для отмены нажмите Enter. После применения выйдите из учётной записи и войдите снова, чтобы Windows перечитала настройки.

Сборка ориентирована на Windows 11, включая 26H2. Она использует встроенный Windows PowerShell 5.1. BAT-файлы задают `ExecutionPolicy Bypass` только для запускаемого процесса PowerShell. Системная политика выполнения при этом сохраняется.

## Жёсткие профили Windows 11

Распакуйте весь ZIP, запустите нужный `.cmd`, введите `Y` и после применения перезагрузите Windows. Запуски выполняются напрямую. **HARD** объединяет три профиля, которые также можно применить отдельно.

| Файл | Что меняет |
| --- | --- |
| [HARD.cmd](HARD.cmd) | Применяет **POWER-MAX**, **BACKGROUND-OFF** и **DESKTOP-FAST** одним запуском. |
| [POWER-MAX.cmd](POWER-MAX.cmd) | Копирует текущую схему питания и активирует отдельную схему для работы от сети. Для доступных параметров CPU выставляет `PERFEPP=0`, `PERFBOOSTMODE=2` и `CPMINCORES=100`. На совместимых системах это отдаёт приоритет производительности и отключает парковку ядер. Нагрев и расход энергии могут вырасти. Параметры работы от батареи наследуются из исходной схемы. |
| [BACKGROUND-OFF.cmd](BACKGROUND-OFF.cmd) | Отключает захват Game Bar, фоновый режим Edge и Chrome и предварительный запуск Edge. Расширения могут перестать присылать уведомления, пока браузер закрыт. |
| [DESKTOP-FAST.cmd](DESKTOP-FAST.cmd) | Уменьшает анимации окон и панели задач, отключает прозрачность и задержку открытия классических подменю. |
| [UPDATE-LIMIT.cmd](UPDATE-LIMIT.cmd) | Отключает обмен обновлениями между ПК и ограничивает фоновые загрузки Delivery Optimization до 2048 КБ/с. Автоматические загрузки могут идти дольше. |
| [APP-BACKGROUND-OFF.cmd](APP-BACKGROUND-OFF.cmd) | Запрещает фоновую работу приложений, на которые действует политика Windows. Некоторые уведомления и синхронизация могут перестать работать. |

**HARD**, **POWER-MAX**, **UPDATE-LIMIT** и **APP-BACKGROUND-OFF** запрашивают права администратора. Подтверждайте запрос под той же учётной записью. Два последних скрипта предназначены для Windows 11 Pro, Enterprise и Education. Работа параметров CPU зависит от процессора и прошивки. Если Windows не даёт применить схему питания, `HARD.cmd` применит настройки фона и рабочего стола и покажет `(PARTIAL)`.

## Для конкретных проблем

| Файл | Когда использовать |
| --- | --- |
| [GAME-FSO-OFF.cmd](GAME-FSO-OFF.cmd) | Если одна игра дёргается при переходе в полноэкранный режим или конфликтует с оверлеем. Закройте игру, укажите её `.exe`, подтвердите и запустите игру снова. |
| [MPO-OFF.cmd](MPO-OFF.cmd) | Если на ПК с NVIDIA мерцают или дёргаются окна, в том числе при их изменении размера. Требуются права администратора и перезагрузка. |

Эти переключатели запускаются отдельно. Условия для Ethernet, USB, HAGS и других настроек разобраны в [дополнительных твиках](docs/OPTIONAL-TWEAKS.md).

## Что выбрать

| Пункт | Действие | Когда полезно |
| --- | --- | --- |
| **1 · Monitor refresh rate** | Открывает дополнительные параметры дисплея | Проверьте выбранный монитор и частоту, особенно после установки драйвера или подключения нового экрана. |
| **2 · Windows startup apps** | Открывает управление автозагрузкой | Отключите ненужные лаунчеры и приложения, если они загружают ПК после входа. |
| **3 · Turn off Windows game capture** | Отключает захват игр Windows для текущей учётной записи | Если не пользуетесь клипами и записью через Game Bar. Для отключения только фоновых клипов используйте переключатель «Записывать произошедшее» в **Параметры → Игры → Записи**. |
| **4 · Close selected app windows** | Показывает текущую загрузку CPU браузерами и лаунчерами и предлагает закрыть выбранное приложение | Если браузер или лаунчер создаёт нагрузку. Приложение может предложить сохранить работу или остаться в области уведомлений. Доступно также через [PROCESSES.cmd](PROCESSES.cmd). |
| **5 · Reduce desktop animations and transparency** | Убирает прозрачность и часть анимаций окон и панели задач | Если предпочитаете более быстрые переходы и простой вид рабочего стола. |
| **6 · Turn off Windows pointer acceleration** | Отключает ускорение указателя и сохраняет его скорость | Если хотите одинаковое перемещение курсора при одинаковом движении мыши. Игры с прямым вводом обычно обходят эту настройку. |
| **7 · Graphics settings** | Открывает параметры графики Windows | Здесь доступны настройки графики для отдельных игр, включая оптимизации для оконного режима. HAGS зависит от видеокарты и драйвера. |
| **8 · Game Mode settings** | Открывает страницу игрового режима | Если нужно проверить состояние Game Mode или сравнить поведение с ним и без него. |
| **9 · Windows Update delivery settings** | Открывает оптимизацию доставки | Если фоновые загрузки обновлений занимают канал, проверьте активность и доступные ограничения пропускной способности. |
| **10 · Mouse and USB diagnostics** | Сохраняет локальный отчёт в `reports/` | Если мышь зависает или пропадает из системы. Перед публикацией отчёта удалите идентификаторы устройств. |
| **11 · Restore saved script changes** | Возвращает настройки, сохранённые скриптами | То же действие доступно через [RESTORE.cmd](RESTORE.cmd). |

Пункт **4** измеряет загрузку примерно за одну секунду и складывает вклад процессов одного приложения. Процент считается от общей мощности логических процессоров. Приложения отсортированы по нагрузке. Перед закрытием нужно выбрать приложение и ввести `CLOSE`.

Для игр на GeForce см. [настройку NVIDIA и CS2](docs/NVIDIA.md). Параметры драйвера применяются вручную в профиле конкретной игры.

## Как откатить изменения

1. Запустите [RESTORE.cmd](RESTORE.cmd) из той же распакованной папки, под той же учётной записью Windows. После профилей с запросом UAC используйте «Запуск от имени администратора».
2. Введите `RESTORE`. Скрипт возвращает сохранённые значения меню и профилей от новых к старым. Если схема CPU Max активна, откат переключает Windows на предыдущую схему и удаляет созданную копию. Копии настроек хранятся в `backups/release-v1/`. Если изменили ту же настройку вручную после запуска скрипта, откат вернёт значение из копии.
3. Перезагрузите Windows. Настройки, которые вы меняли вручную в Windows, игре или панели NVIDIA, возвращаются там же. Закрытое приложение можно открыть заново.

Если вы раньше запускали старые `MAX.cmd`, `ULTRA.cmd` или другие скрипты из экспериментальной ветки, восстановите их настройки через `RESTORE.cmd` той версии и её папку с резервными копиями.

## Как проверить результат

Для рабочего стола повторите действие, на котором были видны рывки. Для игры сравните один и тот же участок или повтор при одинаковых настройках, после прогрева. Смотрите на график времени кадра и редкие пики: средний FPS может остаться прежним, даже когда рывков стало меньше.
