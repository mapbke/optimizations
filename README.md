# optimizations — Windows 11 26H2 / CS2 / FACEIT

Набор **прозрачных и обратимых** настроек Windows 11 для плавной работы системы и проверки игровой производительности. Ориентирован на обычные игровые ПК (в том числе i5-14600KF + RTX 4060 Ti, 32 GB RAM, 1440p, 260 Hz, Lamzu Maya X).

> Это не «+200 FPS одной кнопкой». Время кадра, 1% low, FPS, температура, драйверы и стабильность важнее количества отключённых служб.

## Новый MAX-пак (самый простой способ)

1. Скачайте ZIP репозитория, распакуйте.
2. Запустите **`MAX.cmd`** и подтвердите UAC, затем введите **`APPLY`**. Скрипт покажет изменения и автоматически сохранит исходные значения.
3. Перезагрузитесь. Для более радикальной деактивации необязательных служб и планировщика откройте **`EXTRAS.cmd`** — отключение Windows Search / SysMain / телеметрии там отдельно и с предупреждением.
4. Для полного отката используйте **`RESTORE.cmd`**. Для очистки старых пользовательских TEMP-файлов — **`CLEAN.cmd`**.

**`MAX.cmd` — это реальный пакет настроек, а не диагностический тест:** Game DVR, анимации Windows, фоновые предложения и контент, Edge Startup Boost / Background Mode, Windows Search web suggestions, Widgets, mouse 6/11 + EPP off, отдельный клон текущей схемы питания. Для питания **на сети** в клоне выключаются USB selective suspend и PCI Express ASPM. Изменения могут повысить энергопотребление, но **не гарантируют снижения задержки**. Старый план питания сохраняется.

**Не отключается:** Defender, Firewall, Windows Update, TPM 2.0, Secure Boot, VBS/HVCI, IOMMU, виртуализация, GameInput и устройства USB/HID, чтобы не испортить FACEIT или контроллеры.

**Внимание:** `EXTRAS.cmd` при выборе 5 намеренно отключает **WSearch, SysMain, DiagTrack, MapsBroker** и часть CEIP tasks. Это может ухудшить поиск, предзагрузку и карты Windows. Все состояния служб/задач сохраняются для отката. Отключение индексатора и SysMain не равнозначно ускорению: на ряде ПК станет хуже.

## Быстрый запуск
1. Скачайте репозиторий ZIP, распакуйте в постоянную папку.
2. Откройте **START.cmd**. Права администратора для обычных настроек **не нужны**.
3. Сначала выберите **1 — Diagnostic report**, запустите тест CS2 (3 одинаковых прогона).
4. Примените **2 — Safe profile**; **3 — Gaming profile** только после ознакомления с изменениями.
5. Если нужно, **4 — Mouse 1:1** (EPP off, Windows pointer speed 6/11).
6. Перезагрузите Windows, повторите тест и сравните показатели.
7. **9 — Undo all backed-up changes** вернёт сохранённые значения реестра и планы питания.

## Меню и последствия

| Пункт | Действие | Отмена |
|---|---|---|
| 1 Report | Снимок версии Windows, GPU, драйверов, питания, VBS/TPM, процессов | Ничего не меняет |
| 2 Safe | Отключение пользовательского фонового захвата Game DVR | Да, снимок реестра |
| 3 Gaming | Safe + прозрачность интерфейса Windows OFF (косметика, НЕ обещание FPS) | Да, снимок реестра |
| 4 Mouse | Отключение Enhance Pointer Precision, скорость указателя 6/11 | Да, снимок реестра |
| 5 Optional processes | Интерактивное завершение выбранных несущественных процессов | Перезапуск программ |
| 6 Optional apps | Интерактивное удаление ТОЛЬКО текущему пользователю части предустановленных приложений | Не автоматически, магазин |
| 7 High performance | Переключение на встроенный план «Высокая производительность», если доступен | Да, снимок плана |
| 8 Compare | Сравнение CSV с замерами до и после | Ничего не меняет |
| 9 Undo | Восстановление сохранённых ключей/плана в обратном порядке | Не относится к удалённым Appx |
| 10 Input diagnostics | Проверка мыши, драйверных статусов и USB-устройств, без изменений | Ничего не меняет |
| 11 Startup review | Обзор автозагрузки и переход в официальные настройки Windows | Изменения только вручную |
| 12 MAX | Набор глубоких пользовательских настроек + клонированный игровой план питания | Да |
| 13 EXTRAS | По выбору WSearch, SysMain, DiagTrack, MapsBroker и CEIP задачи | Да |
| 14 CLEAN | Удаление старых пользовательских временных файлов | Нет, необратимо |
| 0 Exit | Выход | — |

При каждом изменении реестра сохраняется точный снимок в `backups/`. Папки `backups/`, `reports/` и результаты измерений не коммитятся в Git.

**Для готового игрового пресета — MAX.cmd; для максимального вмешательства — EXTRAS.cmd.** Gaming в первую очередь меняет внешний вид интерфейса, а не ускоряет ядро, USB и GPU. Для CS2 важнее режим отображения, драйвер GPU, температура/частоты и стабильность USB/радиоканала.

## Не делаем
- Не отключаем **Microsoft Defender, Windows Update, TPM, Secure Boot, VBS/HVCI, IOMMU**, не меняем BCD и ядро ради маркетингового FPS.
- Не меняем **HPET, timer resolution, TSC, MSI interrupts, сетевые глобальные параметры**, affinity/priority системных процессов.
- Не применяем «полный debloat», не трогаем Microsoft Store, Windows Security, WebView2, службы звука и HID/USB.
- Не устанавливаем сторонние твикеры, драйверы, exe-файлы или неизвестные утилиты.
- Не навязываем глобальное **Resizable BAR = On**; оно управляется per-game в NVIDIA App.

## Профиль мыши
REG-файл `reg/mouse-linear.reg` можно просмотреть вручную. Но лучше использовать пункт 4: он сохраняет старые значения для отката. Параметры реестра Windows влияют на **курсор**, а в CS2 с raw input не делают сенсор магически точнее. Зависания сенсора и USB этим не исправляются.

## Resize BAR по последнему ролику Astro
См. [docs/NVIDIA-ReBAR.md](docs/NVIDIA-ReBAR.md). Новая NVIDIA App 11.0.9 предоставляет **Graphics → Program Settings → Driver Settings → Resizable BAR**, отдельно для каждой игры. В некоторых играх повышение FPS возможно, в других — регресс.

## Проверка результатов
См. [docs/CS2-Testing.md](docs/CS2-Testing.md). **Нельзя** судить по числу процессов или по одному матчу. Прогоните одинаковую сцену минимум трижды на одинаковых условиях и сравните Avg FPS, 1% Low, frametime.

## Совместимость
Windows 11 **26H2** (с родственной веткой 24H2/25H2). Проверки обрабатывают неизвестные службы/отсутствующие параметры без принудительного вмешательства. Все скрипты локальные, только PowerShell 5.1 + CMD; интернета не требуют. **Проверка на реальном компьютере под Windows необходима** — разработка/код-ревью не заменяют запуск и тесты.
