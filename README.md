# optimizations

**Набор открытых скриптов для настройки Windows 11:** управление фоновыми функциями, электропитанием, игровыми параметрами и дополнительными компонентами системы.

Проект предназначен для пользователей, которые хотят контролировать изменения в Windows без установки сторонних оптимизаторов. Каждый инструмент можно запустить отдельно, а для большинства системных настроек предусмотрено резервное копирование и восстановление.

> [!IMPORTANT]
> Оптимизация не гарантирует увеличение FPS или снижение задержки ввода. Результат зависит от оборудования, версии Windows, драйверов и конкретной игры. Перед применением прочитайте описание выбранного режима.

## Возможности

- Настройка игровых и фоновых функций Windows.
- Отключение записи игрового процесса в фоне (Game DVR).
- Настройка параметров указателя мыши.
- Управление схемами электропитания.
- Дополнительные настройки GPU и Hardware-Accelerated GPU Scheduling (HAGS).
- Настройка доставки обновлений Windows без P2P.
- Просмотр и завершение выбранных второстепенных процессов.
- Выборочное удаление предустановленных приложений текущего пользователя.
- Очистка старых временных файлов.
- Диагностика системы, устройств ввода и сравнение результатов тестов.
- Сохранение исходных параметров для последующего отката там, где это поддерживается.

Скрипты работают локально на базе **CMD и Windows PowerShell 5.1**. Для их выполнения не требуется установка дополнительного ПО.

## Требования

| Компонент | Требование |
| --- | --- |
| Операционная система | Windows 11 (основной целевой выпуск — 26H2) |
| Совместимость | 24H2/25H2 — близкие выпуски; не все действия проверены |
| PowerShell | Windows PowerShell 5.1 |
| Запуск | Права администратора для действий, меняющих системные настройки |
| Интернет | Для работы скриптов не требуется |

> [!NOTE]
> Полноценное тестирование пакета на всех конфигурациях Windows не проводилось. Некоторые параметры зависят от редакции ОС, версии драйверов и настроек оборудования.

## Быстрый старт

1. Скачайте архив через **Code → Download ZIP** на странице репозитория или клонируйте его:

   ```powershell
   git clone https://github.com/mapbke/optimizations.git
   ```

2. Распакуйте архив в постоянную папку, если использовали ZIP.
3. Откройте `START.cmd` — главное меню инструментов.
4. Выберите нужное действие. Для первого знакомства рекомендуется **SAFE** (пункт 2); для расширенного набора настроек предусмотрен **MAX** (пункт 12).
5. Изучите предупреждения, подтвердите применение настроек и перезагрузите компьютер, если это требуется.

**Прямой запуск:** `MAX.cmd`, `ULTRA.cmd` и `RESTORE.cmd` доступны без перехода через главное меню.

> [!TIP]
> Не обязательно применять все изменения сразу. Запускайте только нужные инструменты: например, `GPU.cmd` для графических параметров или `NETWORK.cmd` для настройки доставки обновлений.

## Режимы оптимизации

| Режим | Что изменяет | Риск побочных эффектов | Как запустить |
| --- | --- | --- | --- |
| **SAFE** | Отключает фоновую запись Game DVR | Низкий | `START.cmd` → 2 |
| **GAMING** | SAFE + отключение прозрачности интерфейса | Низкий | `START.cmd` → 3 |
| **MAX** | Расширенные пользовательские настройки, фоновые функции и отдельная схема питания | Средний | `MAX.cmd` |
| **ULTRA** | MAX + отключение выбранных служб и задач Windows | Повышенный | `ULTRA.cmd` |

### MAX

Основной расширенный профиль. Включает настройки Game DVR, визуальных эффектов, фонового содержимого, параметров поиска, Widgets, Edge, указателя мыши и электропитания.

Создаёт отдельную схему питания на основе текущей. Для работы от сети в ней отключаются **USB Selective Suspend** и **PCI Express ASPM**. Это может увеличить энергопотребление и не гарантирует улучшения отзывчивости.

Перед изменениями сохраняются исходные значения, необходимые для предусмотренного скриптами отката.

### ULTRA

Агрессивный профиль, который дополнительно может отключать:

- **Windows Search (WSearch)** — индексирование и связанные функции поиска;
- **SysMain** — оптимизацию загрузки часто используемых приложений;
- **DiagTrack** — компоненты диагностической телеметрии;
- **MapsBroker** — функциональность загруженных карт;
- некоторые задачи **CEIP** в планировщике заданий.

Эти изменения могут **ухудшить** удобство работы, поиск файлов и запуск приложений. ULTRA не следует считать автоматически более быстрым вариантом MAX.

> [!WARNING]
> Начинайте с минимального количества изменений. Если система работает стабильно, нет необходимости отключать службы только ради уменьшения их числа.

В `START.cmd` также доступны диагностический отчёт, проверка устройств ввода, просмотр автозагрузки и сравнение CSV-файлов тестирования.

### Настройка мыши

Профиль **MOUSE** отключает Enhance Pointer Precision и устанавливает скорость указателя Windows **6/11**. Это влияет на обработку перемещения системного курсора; в играх, использующих raw input, результат может отличаться или отсутствовать.

Если мышь теряет связь, зависает или пропускает движения, причины следует искать в устройстве, USB-подключении, драйверах и радиоканале. Изменение реестра не устраняет аппаратные неисправности.

### NVIDIA и Resizable BAR

В проекте есть отдельная инструкция по проверке Resizable BAR для конкретных игр. Глобальное включение не рекомендуется без сравнения результатов.

Подробнее: [NVIDIA / Resizable BAR](docs/NVIDIA-ReBAR.md).

## Восстановление изменений

Чтобы вернуть сохранённые параметры:

1. Запустите **`RESTORE.cmd`** либо выберите пункт 9 в `START.cmd`.
2. Следуйте подсказкам скрипта.
3. Перезагрузите Windows.
4. Проверьте, что нужные настройки восстановлены.

Резервные копии находятся в каталоге `backups/`. **Не удаляйте эту папку, пока не убедитесь, что откат больше не нужен.**

**Ограничения восстановления:** удалённые приложения и очищенные временные файлы автоматически не возвращаются. Импорт `.reg` вручную также может обойти встроенное резервное копирование. Откат распространяется только на изменения, для которых скрипты сохранили необходимое исходное состояние.

Рекомендуется самостоятельно создать **точку восстановления Windows** перед использованием расширенных режимов. Точка восстановления не заменяет резервную копию личных файлов.

## Безопасность и ограничения

Проект **не предназначен для обхода античитов или отключения системных механизмов защиты**. Скрипты не должны отключать:

- Microsoft Defender, Windows Firewall и Windows Update;
- TPM 2.0, Secure Boot и VBS/HVCI;
- IOMMU и системные механизмы виртуализации;
- драйверы USB/HID и критические службы ввода.

Пакет не применяет сомнительные глобальные настройки HPET, TSC, прерываний, BCD, приоритетов системных процессов или сетевого стека ради недоказанного повышения FPS.

**Для игроков с FACEIT:** требования античита могут изменяться. Перед изменениями проверяйте [официальную документацию FACEIT](https://support.faceit.com/hc/en-us/articles/23117181142556-Windows-Security-Requirements-FAQ). Отсутствие намеренного отключения защитных функций не является гарантией совместимости.

Скрипты запускаются с разрешениями пользователя и иногда администратора. **Перед запуском проверяйте содержимое файлов.** Не используйте пакет из неофициальных перепаковок.

## Проверка результата

Меньшее количество процессов и «чище» выглядящий диспетчер задач сами по себе не означают более высокую производительность.

Для сравнения:

1. Зафиксируйте исходные условия: версия драйвера, разрешение, настройки игры и фоновые приложения.
2. Выполните несколько одинаковых прогонов до изменения параметров.
3. Примените один профиль или одну группу настроек.
4. Повторите тест в тех же условиях.
5. Сравните **Average FPS**, **1% Low**, время кадра (*frametime*) и стабильность.

Проводите не менее трёх прогонов на каждую конфигурацию, если это возможно. При отсутствии воспроизводимого улучшения оставьте настройки по умолчанию.

Подробная методика: [Тестирование CS2](docs/CS2-Testing.md).

## Устройство проекта

```text
optimizations/
├── START.cmd          # Главное меню
├── MAX.cmd            # Расширенный профиль
├── ULTRA.cmd          # Агрессивный профиль
├── RESTORE.cmd        # Восстановление настроек
├── GPU.cmd            # Параметры графики
├── NETWORK.cmd        # Сетевые параметры
├── EXTRAS.cmd         # Дополнительные службы
├── scripts/           # PowerShell-логика
├── reg/               # Отдельные настройки реестра
├── docs/              # Инструкции и тестирование
└── README.md
```

Рабочие каталоги `backups/` и `reports/` создаются для локальных результатов и не предназначены для публикации вместе с персональными данными.

## Обратная связь

Сообщения об ошибках, предложения и улучшения приветствуются в [Issues](https://github.com/mapbke/optimizations/issues).

При сообщении об ошибке желательно указать версию Windows, выполненный скрипт, наблюдаемое поведение и шаги воспроизведения. **Не публикуйте личные данные из диагностических отчётов.**

Изменения в код можно предложить через Pull Request. Для твиков производительности желательно приводить объяснение механизма, возможных побочных эффектов и воспроизводимые измерения.
