# Дополнительные твики Windows 11

| Настройка | Когда есть смысл |
| --- | --- |
| Полноэкранная оптимизация | Для проблемы в одной игре используйте [GAME-FSO-OFF.cmd](../GAME-FSO-OFF.cmd). Он меняет настройку совместимости только выбранного файла, сохраняет существующие флаги и записывает исходное значение для отката. При нормальной работе оставьте полноэкранную оптимизацию включённой. [Разбор Microsoft](https://devblogs.microsoft.com/directx/demystifying-full-screen-optimizations/) |
| MPO | [MPO-OFF.cmd](../MPO-OFF.cmd) предназначен для мерцания и рывков окон на системе с NVIDIA. Он выключает MPO для всей системы. Обычно MPO помогает видеокарте выводить несколько слоёв и экономить энергию. [Документация NVIDIA](https://nvidia.custhelp.com/app/answers/detail/a_id/5157) |
| HAGS | Если проблема появилась после смены драйвера или включения аппаратного планирования GPU, переключите HAGS в параметрах графики Windows и перезагрузитесь. Пункт доступен на поддерживаемом железе. [Настройка NVIDIA и CS2](NVIDIA.md) |
| Ethernet | В свойствах конкретного проводного адаптера можно сравнить включённую и выключенную модерацию прерываний. Отключение уменьшает задержку пакетной обработки ценой более частых прерываний и дополнительной загрузки CPU. EEE и Green Ethernet стоит сравнивать отдельно при проблемах с линком или скачках после простоя, если драйвер показывает эти параметры. [Документация NDIS](https://learn.microsoft.com/en-us/windows-hardware/drivers/network/interrupt-moderation) |
| USB selective suspend | Если устройство пропадает или перестаёт отвечать после простоя, можно отдельно проверить параметр «Временное отключение USB-порта» в настройках используемой схемы питания. Сравнивайте поведение при работе от сети. Microsoft рекомендует держать эту функцию включённой при обычной работе. [Документация Microsoft](https://learn.microsoft.com/en-us/windows-hardware/drivers/usbcon/usb-selective-suspend) |
| Планировщик и MMCSS | Приоритеты MMCSS имеют смысл для приложений, которые регистрируют свои потоки в соответствующей категории. Значение `SystemResponsiveness=0` Windows приводит к 20. Поэтому этот конкретный твик не освобождает дополнительные 20% CPU. [Документация Microsoft](https://learn.microsoft.com/en-us/windows/win32/procthread/multimedia-class-scheduler-service) |
| Группировка служб | Порог `SvcHostSplitThresholdInKB` влияет на число процессов и изоляцию служб. Меньшее число процессов может снизить расход памяти. Для файлов реестра с типом DWORD числа после `dword:` записываются в hex. Например, десятичные 33 554 432 КБ записываются как `dword:02000000`. [Описание группировки служб](https://learn.microsoft.com/en-us/windows/application-management/svchost-service-refactoring) |

Чтобы откатить изменения батников, запустите [RESTORE.cmd](../RESTORE.cmd) из той же папки. Если применяли MPO, запустите откат от имени администратора под той же учётной записью и перезагрузите Windows. Настройки Ethernet, USB и HAGS, изменённые вручную, возвращаются на соответствующих страницах Windows.
