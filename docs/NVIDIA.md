# NVIDIA GeForce и CS2

Откройте **Панель управления NVIDIA → Управление параметрами 3D → Программные настройки** и выберите `cs2.exe`. Запишите исходные значения перед изменениями, чтобы потом вернуться к ним. Для других игр используйте их отдельные профили.

| Цель | Настройка |
| --- | --- |
| Плавное изображение без разрывов | Если монитор поддерживает G-SYNC или G-SYNC Compatible, включите адаптивную синхронизацию на мониторе и G-SYNC в панели NVIDIA. Для CS2 включите вертикальную синхронизацию в профиле NVIDIA, выключите её в самой игре и включите NVIDIA Reflex в игре. По рекомендации NVIDIA, такая комбинация ограничивает частоту кадров ниже потолка развёртки, когда Reflex управляет лимитом. |
| Минимальная задержка, разрывы допустимы | Сравните режим с выключенной вертикальной синхронизацией и включённым Reflex. При включённом Reflex оставьте «Режим низкой задержки» драйвера выключенным. |
| Скачки времени кадра при высокой загрузке GPU | Попробуйте ограничить FPS в самой игре до частоты, которую ПК удерживает в тяжёлых сценах. Меняйте один лимит за раз и проверяйте время кадра. |

Для Windows 11 оптимизация оконных игр относится к совместимым играм DirectX 10/11 в оконном режиме и режиме без рамки. Аппаратное планирование GPU (HAGS) сравнивайте отдельно через параметры графики Windows, если переключатель доступен. После изменения HAGS перезагрузите ПК.

Для возврата используйте исходные значения в панели NVIDIA и в игре. Кнопка «Восстановить» в программных настройках сбрасывает весь выбранный профиль драйвера.
