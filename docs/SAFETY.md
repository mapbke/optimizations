# Что специально исключено

**Никаких гарантий прироста FPS.** Изменение ОС ради снижения чисел в диспетчере задач само по себе ничего не доказывает.

- Defender / Firewall / Windows Update: не отключаем, потому что риски больше не подтверждённого прироста.
- Secure Boot / TPM 2.0 / VBS / HVCI / Memory Integrity / VT-d / IOMMU: не отключаем. FACEIT требует часть этих функций сейчас и расширяет охват.
- HPET / bcdedit useplatformclock / disabledynamictick / Timer Resolution: это не универсальное снижение input lag; может быть хуже.
- Изменения приоритетов прерываний MSI, латентности DPC через случайные реестры: только после конкретной диагностики и проверки драйверов.
- Nagle/NetworkThrottlingIndex/TcpAckFrequency: не используем «шаблоны 0 ping», не обещаем влиять на серверную регистрацию попаданий.
- Массовое отключение служб через sc config или реестр: не делаем. Часть служб запускается по требованию и зависит от компонентов ОС.
- Драйверы/устройства HID, USB, Bluetooth, аудио: не трогаем, чтобы не сломать Lamzu, контроллеры, звук, FACEIT.
- «Отключить все задачи», «удалить весь UWP»: нет. Удаление необязательных приложений строго интерактивное и не восстанавливается Undo.

## Откат
START.cmd → 9. Возвращает все изменённые скриптами ключи реестра и план питания из backups/*.json в порядке, обратном применению. Снятие флага «прозрачность»/изменение указателя может требовать выхода из сеанса. Если .reg применяли напрямую, штатной резервной копии от этого пакета **нет**; сначала используйте скрипты.

Удаление Appx отдельным пунктом не откатывается этим механизмом. Удалённые приложения можно заново установить через Microsoft Store, если они доступны.

## Никакой телеметрии от набора
PowerShell скрипты ничего не загружают и не отправляют. Отчёты локальные и содержат имена процессов/программ автозапуска — перед пересылкой проверьте их на личную информацию.
